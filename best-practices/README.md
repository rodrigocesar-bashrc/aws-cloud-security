# Best practices

Guias práticos de configuração de serviços de segurança da AWS em ambientes multi-conta com AWS Organizations. Cada pasta traz scripts, policies e o passo a passo para reproduzir a configuração em laboratório antes de levar para produção.

## Conteúdo

- **`GuardDuty/`**: configuração do Amazon GuardDuty com conta administradora delegada, monitoramento da Management account e export centralizado de findings.
